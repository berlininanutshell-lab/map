Папка lostarmour/ лежит рядом с index.html. Ничего редактировать не нужно.

Просто загрузите в эту папку KML-файл:
  - latest.kml          — сайт всегда возьмёт его первым, или
  - 2026-10-15.kml      — файл с датой в имени (ГГГГ-ММ-ДД.kml).

Если файлов несколько, на сайте появится выпадающий список, по умолчанию
открывается latest.kml, а если его нет — самый новый по дате.
Даты ищутся за последние 150 дней.

Если папки нет или она пустая, сайт использует встроенную копию от 2026-09-30.

Необязательно: ukraine.geojson
Если положить в эту папку файл ukraine.geojson (контур Украины с Крымом, Polygon/
MultiPolygon в GeoJSON), сравнение будет считать Russian Control строго внутри
этого контура. Без него контур Украины оценивается автоматически
(Ukrainian Control + области LostArmour + щели между ними до ~10 км).

Необязательно: seas.geojson
Файл seas.geojson — полигоны морей (Азовское, Чёрное и т.д., GeoJSON Polygon/MultiPolygon).
Если он есть, моря вырезаются и из областей LostArmour, и из Russian Control: ни вода,
ни кусочек береговой линии не засчитывается как суша (например, «5 км² Бердянска»).
Полигон моря должен покрывать только воду, иначе он срежет и часть суши.
